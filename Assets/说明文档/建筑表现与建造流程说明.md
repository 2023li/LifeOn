1. 在 BuildingArchetype 资源的 Inspector 中，Graph Asset 字段会显示当前绑定的图资产，并提供 **打开节点编辑器** 按钮。
2. 若尚未绑定图资产，点击按钮会弹出提示并引导保存新图；系统会自动调用 FromArchetype 将现有等级与规则导入图节点。
3. 节点编辑器左上角的 Save 按钮会执行 ToArchetype，同时保持 Graph ↔ Archetype 双向引用；Import 可随时从原型重新拉取旧数据。
4. Tools/资源路由/生成默认资源定义 现在会同时输出/更新对应的图资产，确保脚本化生成与图编辑一致。

### 旧数据迁移建议
- 先在 Project 中选中历史 BuildingArchetype，使用 Inspector 按钮创建/打开图，然后在编辑器中执行 Import 验证节点结构。
- 对于已有图但缺乏关联的情况，打开窗口后会自动补齐引用，无需手动修改脚本。

### 编译错误排查
- 出现 GraphAsset 或 SetLinkedArchetype 相关编译错误时，确认新脚本已保存，并在 Unity 内重新触发编译（Assets/Refresh）。
- 如果节点编辑器引用缺失，重复点击 Inspector 按钮让窗口重新建立引用，必要时重新生成图资产。
- 若 ResourceRouting 生成的默认资产出现错配，重新运行菜单命令可同步图与原型数据。
